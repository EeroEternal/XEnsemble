跑通 PostgreSQL 迁移

周涛 128 次安装 3 天前更新
来自 3 个相似会话 成功退出 4 个文件
适用场景

需要为任何 Node/TS 项目新增或修改数据库迁移时使用。涵盖 drizzle-kit 与手写 SQL 两种路径。

步骤
  1. 确认现有 journal 最大 idx 与迁移目录
  2. 用 drizzle-kit generate 或手写 SQL 生成新迁移
  3. 更新 schema.js 定义并同步 _journal.json
  4. 运行 db:migrate 并验证幂等重跑
注意事项

CASCADE 外键需与目标表引用一致；PlanetScale 等托管库无 CREATE SCHEMA 权限时需走公共表追踪。
